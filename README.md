# API Integration in Practice 🔌

Practical patterns for integrating with third-party APIs, built with **NestJS** and **TypeScript**.

Calling an endpoint is the easy part. The hard part is everything around it: the other side goes down, returns something the docs never mentioned, rate-limits you, or sends the same webhook twice. This repo collects the patterns I use to handle that, one small runnable example per topic.

It accompanies a post series on [LinkedIn](https://www.linkedin.com/in/mohammed-elfayoumy-66548222a). Each part gets a post and a folder here.
